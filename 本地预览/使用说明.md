# 行间 · 本地旅行工作台预览

双击 `启动预览.cmd`，保持窗口打开，浏览器访问 http://127.0.0.1:18646/ 。也可执行 `E:\node.exe server.cjs`。仅监听本机，不部署。

桌面优先：先选择有/无行程，填入基本需求；进入后自由切换交通、住宿、地点、每日安排和需求。初始地图收起。每日安排可主动载入杭州示例，增删、换日、排序和撤销；地图对应变化。已有行程原文独立保留，不做自动解析。原文和自由备注按文本显示。

所有酒店为区域占位，交通班次和价格虚构，不保证相应航线存在，不提供查询、订票或预订。日期比较不是真实票价。聊天只演示三种预设操作；其他文字保存为备注，不调用 AI。总费用按示例价格、人数、房间数和住宿晚数计算，并包含每人每天 100 元餐饮/市内交通预留。路线为地理点顺序连线，不是道路导航，未验证交通时长、开放预约和约束。

Leaflet 1.9.4 分发文件保存在 vendor，来源 https://unpkg.com/leaflet@1.9.4/dist/ 。底图来自 OpenStreetMap，需要联网，包含地图署名；无法加载时显示明确标注的经纬度备用示意图。不下载批量地图瓦片。初始不发起地图瓦片请求。

需求保存在此浏览器 localStorage 中；“我的需求”可导出 JSON 备份。重置须确认。不同浏览器、端口或无痕窗口不共享数据。未制作手机 App，窄屏仅作基本布局兼容。
