# 高德地图操作与路线统计实施计划

**范围：** 按用户更正，本轮只接高德地图操作与行程统计，不配置、调用或新增 AI 模型。

## 任务 1：地图内搜索与图层

- 在右侧地图加入紧凑的地点搜索：使用现有高德地点接口，展示名称、地址和城市；选择结果后定位到底图并打开地点卡，不额外制造单点图钉。收藏仍保存在工作台。
- 加入卫星图、实时路况开关，直接使用高德 JS API 图层；地图未加载时明确提示，不展示假图层。保留已有收藏、缩放、地图开关和行程路线。
- 验收：模拟同名地点、搜索失败、选择与收藏；独立浏览器验证真实搜索及真实高德图层开关，不能操作用户浏览器会话。

## 补充任务：地图上选起终点并查询路线

- 地点详情提供“设为起点”“设为终点”；地图上的路线面板显示双方、交通方式与查询按钮，调用现有高德路线接口并在地图画返回的线路。
- 地图单次路线显示距离、时间、已返回的公交票价或每车过路费及来源时间；单次查询不会自动计入每日行程统计，避免重复计算。
- 两端不同城市且选择公交时明确提示当前只支持同城公交；接口失败、无路线或缺少图形明确展示，不画伪路线。查询过程中改点时旧结果不可覆盖新选择。
- 验证地图搜索两个地点、设置起终点、查询路线、查询失败与旧请求保护，保留已有行程和本机收藏。

## 补充任务：地图选择住宿地点

- 地点卡支持“设为住宿”及取消，选择后保存至本地并自动收藏，刷新后保留；它只是位置选择，不代表预订或有房价。
- 行程摘要和每日安排显示当前选中的住宿地点，费用明确待查。选择新的真实地点时停止计算旧示例酒店费用；已有住宿原文不覆盖。
- 验证实际搜索结果、已有住宿原文、取消/刷新和空价格，确保不会冒充预订。

## 任务 2：各天真实路线保存与统计

- 每天保存最近一次已查询的路线结果；展示当天总路程与交通时间、按交通方式列明已知费用，并在总览提供跨天的已知合计。
- 数据签名绑定日期、目的地、地点顺序和坐标。修改地点、顺序、日期或目的地后旧路线不参与当前统计；更新期间切换日期不能覆盖新行程。兼容并保留旧版单天路线。
- 显示缺失段数及未查询天数：缺失距离、时间、公交票价或驾车过路费不能默认为零；公交票价按每人和同行人数分别显示，驾车仅列每车过路费，不估算油费/停车费。
- 统计仅覆盖已查询的市内地点间路段，不把已选车票、酒店、景点游览、等候或未查询路段算进去；不把当前演示预算当真实总花费。
- 验收：以模拟接口先写失败测试，覆盖两天持久化、已知/未知费用、部分失败、变更失效、旧路线兼容、刷新保留；再用实际高德结果验证一条路线。

## 任务 3：整体验证

- 重新执行地图地点、收藏、车站、路线与原有行程回归；独立浏览器截图复核桌面显示。
- 若当前 18647 后端仍为旧进程，既有公交修复需重启才生效；不假称已加载。
- 更新使用说明，记录已验证与未验证内容，不写用户个人或项目长期记忆，不提交或部署。
