# 为项目制作 Skill

先确定触发场景、真实使用者和预期结果；只有规则、流程或工具能跨任务复用时才单独建技能。项目稳定约束放项目指令中，业务实现事实以当前代码为准。技能不授予用户未授权的外部操作。

在仓库根目录运行 `node .agents/skills/travel-skill-builder/scripts/create-skill.cjs <英文名称> <中文用途>` 创建 `.agents/skills/<英文名称>/SKILL.md`。名称仅允许小写字母、数字和连字符；已有目录不会覆盖。脚手架只是起点：补充实际流程、必要限制和引用，再检查名称、描述、路径和实际使用场景。重复性且确定的操作可放 `scripts/`；按需加载的详细资料可放 `references/`。

创建后至少检查 YAML 元信息、目录名、引用路径，运行新增脚本，并用具体任务判断技能是否能帮助完成工作。不要声称静态检查已经证明了实际效果。技能文件位于仓库的 `.agents/skills/`，是否被当前工具自动发现取决于运行环境；必要时显式指定技能文件。
