# 历史实践与工具

本页整理 2026-11 的需求、项目记录和工具试验，用于理解工作方式；不代表当前版本的功能状态或完整验收结论。重新执行前要检查源码和实际测试。

## 用户的要求如何变化

- 用户希望尽可能完整复刻高德网页版界面和互动，范围不止驾车、公交、步行路线；曾要求先做独立页面、验证后再接入旅游工作台。不能以静态地图截图冒充可互动地图，也不能把部分功能完成说成全站 1:1。
- 后来用户具体要求先将界面接入工作台、做好互动并写计划执行；要求地图右键菜单真正联动地图、右上角按钮改成高德样式、接入地铁图，并追问路线上的小箭头，要求按高德的视觉标准对照。
- 在新任务中，应先核实用户当前是希望看独立预览还是直接改工作台；后续明确指示优先于这些历史要求。视觉效果需要用户查看，程序测试不能代替用户认可。

## 实际用过的工具和代码

| 工具或位置 | 实际作用和证据边界 |
| --- | --- |
| 高德 JavaScript API 与地图接口 | 地图、搜索、路线和右键事件的真实实现基础；需要配置、网络与额度，响应字段及权限须实际核验。 |
| 高德地铁图 | `旅迹风格预览/public/subway-view.html` 接入地铁图；当时曾用青岛、杭州做实网检查。查看地铁线路不自动加入旅行。 |

| coordtransform | 地图相关的 GCJ-02、WGS-84 坐标转换；应检查数据来源与实际转换方向。 |
| Playwright 与独立浏览器上下文 | `验证工具/check-next-map-isolated.cjs` 使用模拟地图和隔离数据；项目中另有真实地图验收脚本。模拟结果、实网结果、截图和用户视觉验收分别记录。脚本可能包含机器专用浏览器路径，先检查再运行。 |
| 地图截图与人工对照 | 对齐参考版本、视口和操作状态，检查面板、工具栏、路线及箭头。截图能展示对应画面，不能单独证明所有按钮和真实数据可用。 |
| Canvas 路线方向箭头 | 曾尝试在真实路线坐标上绘制箭头，因为当时 SDK 内置箭头在截图中未显示。该尝试当时尚未完成构建与验证；检查覆盖层、缩放和路线几何，不要直接宣称已完成。 |

当时真实地图测试曾覆盖搜索、右键设置起终点与途经点、路线查询及部分地铁互动；这只是指定环境和场景下的历史结果。无头浏览器滚轮缩放未得到有效验证，真人鼠标操作也未验证。

## 曾调研或局部试验的复刻工具

这些工具不是本仓库的依赖，也未证明能一键完整复刻高德地图：

- **Trueclone**：用于逐状态采集、重建与比较的候选工作流；历史上本地命令和部分自带测试通过，未据此证明高德实测成功。精确复制模式有自身授权要求。
- **UIForge**：可辅助录制回放或界面对比。曾在本地测试页出现未录制搜索词返回旧结果的情况，不能将录制回放视作实时搜索；工具箱曾做页面与自身的差异比较，并非高德复刻验收。
- **AI Website Cloner Template**、**website-copy-maker**：曾阅读项目说明作为开发流程或验收候选，未完成针对高德的完整试验。
- **Mirrorframe**：曾运行自带示例，但对 Canvas 和交互支持有限；示例相似度不代表高德实测结果。

原项目还保存了工具箱，但公开源码快照没有包含第三方工具副本或采集资料。需要使用时重新核实来源、版本、授权及安全隔离；普通临时目录不等于受限沙箱。
