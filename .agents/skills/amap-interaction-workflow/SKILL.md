# 高德地图界面与互动工作流

先读项目 README、相关地图代码和 Git 状态，保护既有未提交改动。用户提供截图或指定高德版本时，分别记录参考版本、界面状态与目标；范围覆盖哪些入口以用户本次要求为准。需要对照此前对话、工具使用和已知验证边界时，读取 [历史实践与工具](references/practice-and-tools.md)，不要把旧测试结果当成当前状态。

1. 梳理真实用户动作及其反馈：搜索与详情、地图右键、路线方式和方案、地图图层与工具、地铁等，列出入口、状态、数据来源、异常、关闭与返回。区分截图外观与可用交互。
2. 需要新视觉设计或大范围复刻时，先做独立可操作预览，提供对照给用户确认，再按授权接入工作台；用户明确要求直接接入时按其要求执行。预览应显示真实可拖动地图，不能把静态背景或录制响应冒充实时功能。
3. 用现有 Vue 地图组件、高德 JS API 与本地接口实现实际能力；先核查 SDK、配置、权限与接口。将右键菜单动作绑定点击坐标，路线卡片与地图结果联动；切换条件时防止旧结果覆盖新状态。检查 GCJ-02 与 WGS-84 的转换和标记位置。
4. 查询、切换地图及查看地铁线路不能自动修改旅行数据；收藏、加入行程等持久化操作须由用户主动触发。真实服务失败或字段缺失时显示真实状态，不编造路线和价格。
5. 用独立浏览器上下文和临时旅行进行模拟及必要的实网验证，分别报告结果。对齐参考版本、视口和交互状态截图；检查搜索、右键、路线选择、缩放、覆盖物层级、异常和窗口变化。自动化通过不等于用户视觉验收。

地图接口和第三方工具的能力、成本及可用性可能变化，实际执行前重新核对。第三方采集或复刻工具仅在适用授权和隔离条件满足时使用；不要提供密钥、账号或个人行程。未验证的能力明确列为待验证。
