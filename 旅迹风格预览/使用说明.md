# 旅迹风格的本地预览

访问 http://127.0.0.1:18647/ 。未启动时双击“启动旅迹风格预览.cmd”，然后在浏览器打开上述地址。

本轮主要参考旅迹 Lvji 0.1.1 的新建行程页面：左侧大标题与说明、右侧圆角创建表单、暖灰背景、橙色强调、日期/日期待定切换。保留本项目需求：先问有无行程；已有行程原文默认保留；往返、住宿、地点可以自由选择处理顺序；创建后地图默认打开，可由右上角同一个按钮展开或收起。创建页的整趟预算口径没有照搬对标的人均预算。旅行节奏只保存偏好，不伪称已影响路线算法。

本地核对来源：`../旅迹/12306服务/app-unpacked/dist/renderer/assets/index-BCcmQAtJ.js` 与 `index-J0whmTCi.css`；上游仓库 https://github.com/drfccv/lvji-travel 。布局独立实现，没有复制竞品代码、素材或标识。新增字段与原文保留流程为本项目设计，不声称与旅迹逐项一致。

上一版在 `../本地预览/`，使用 18646 端口。本版单独使用 18647 端口及 `xingjian-lvji-preview-v1` 存储键，互不覆盖。

当前工作台可通过本地 12306 接口查询车次、余票与票价，通过高德搜索地点，查询两点或当天相邻地点的路线；可用性取决于对应服务、密钥和网络，选中车次不代表已购票。高德网页地图可用时优先展示高德，其他情况下使用备用地图；每日地点间的顺序虚线仅为示意，不是道路导航。酒店实时房价需另行配置 RollingGo Key，机票价格供应商尚未接入。预算中的餐饮等金额及杭州示例地点仍是示例，实际地点门票未知时会标明。AI 助手仅为预设交互演示，不会自动规划行程。

验证方式：独立无头 Edge 浏览器，使用新建的临时上下文，不接管桌面或现有浏览器标签页。Playwright 工具与 npm 缓存保存在 E 盘 `../验证工具/`，脚本入口 `check-lvji-preview.cjs`。验收记录和截图位于本目录 `验收/`。

工作台页面已按用户要求改为两栏：左侧包含旅程费用、模块入口和每日安排，并可切换“行程编辑 / 对话助手”；右侧是完整地图，不放聊天或独立侧栏。地图仍由右上角按钮自主展开或收起，展开时占满右栏高度。费用和已选交通住宿摘要随操作更新。使用 `../验证工具/check-two-column.cjs` 验证两栏尺寸、地图铺满、左侧聊天/编辑切换、增删撤销、费用和存储恢复。原 `check-workspace.cjs` 及三栏截图为上一轮历史验收，不再代表当前布局。手机 App 不在本轮范围内。

真实地点可在“想去的地方”中搜索，核对名称与地址后加入待规划，再选择日期加入行程。已安排的地点可移动、移除和撤销，数据保存在当前浏览器；已有交通、住宿和预约文字会保留，但尚未自动进行时间冲突判断。

在每日安排中加入至少两个地点后，可选择公交、步行或驾车，逐段查询当天地点之间的交通。住宿和车站暂不会自动加入这些路段；请求失败或未返回路线图形时会显示提示。后台接口代码更新后需要重启本地预览服务才会生效。

在高德底图上点击原有地点可查看地址、收藏或加入某天；右上角“收藏夹”保存于当前浏览器的工作台，不会同步到高德账号。选定的到达车站和地图选定的已有住宿会自动收藏一次，用户可以自行取消；车站查看使用底图原有地点，不额外覆盖车站图钉。

本轮地图交互补充：待规划地点（已收藏但尚未加入行程）与当天地点同图显示，当天地点是带序号的实心标记，待规划地点是空心圆点、可点击查看详情；加入行程后不再重复显示，备用地图同样区分。地图路线面板新增“交换起终点”，交换后旧方向的结果会被清除并要求重新查询；刷新页面会恢复上次已查路线的起终点与结果。验收脚本为 `../验证工具/check-map-candidates.cjs`（模拟接口）和 `../验证工具/check-map-candidates-live.cjs`（真实高德），截图见本目录 `验收/高德地图-待规划地点同日显示.png` 与 `验收/高德地图-交换起终点后重查.png`。

本轮新增 12306「直达 + 换乘比价」：在往返交通的 12306 真实查询卡片下方，可再查同日期“出发 → 中转 → 到达”的换乘方案（12306 中转查询，最多前 10 条），与直达最低价按去程、返程逐方向对比，并可一键套用最省换乘方案（自动选各段最低有票席别）计入预算。换乘方案可能包含两次换乘或换站换乘，请核对换乘时间；价格为各段有票席别之和，以 12306 下单时为准，不自动购票。后端新增 `/api/rail/interline` 接口，封装本地 12306 MCP 的 `get-interline-tickets`。验收脚本为 `../验证工具/check-rail-interline.cjs`（模拟）和 `../验证工具/check-rail-interline-live.cjs`（真实 12306），截图见本目录 `验收/12306-换乘比价.png`、`验收/12306-套用换乘后.png` 与 `验收/12306-换乘比价-真实数据.png`。

本轮把高德地图控件换成高德原生控件：右下角缩放（`AMap.ToolBar`）、左下角比例尺（`AMap.Scale`）、右上角标准/卫星图层切换（`AMap.MapType`）、左下角定位按钮（`AMap.Geolocation`），实时路况仍保留独立开关；这些控件通过 `AMap.plugin` 按需加载。收藏但未加入行程的地点在地图上改为星标（★）显示（此前是空心圆点），高德与备用 Leaflet 地图一致。自绘的“+ / −”缩放和“卫星图”按钮已移除，卫星切换由原生图层控件接管，备用地图恢复其自带缩放。验收脚本为 `../验证工具/check-map-controls.cjs`（模拟）和 `../验证工具/check-map-controls-live.cjs`（真实高德），截图见本目录 `验收/高德地图-原生控件与星标.png`；`check-map-candidates*.cjs` 已同步改为星标断言。

另修复：收藏但未加入行程的地点，此前只在地图默认视图显示星标，收藏后地图停留在“地点详情”焦点视图时星标会消失，容易被误认为没收藏上。现改为在**所有地图视图**（默认、地点详情、当天路线、路线查询）都渲染星标，收藏后立刻可见；加入行程后仍会去重、转为带序号的当天标记。验收脚本 `../验证工具/check-map-star.cjs`，截图见本目录 `验收/高德地图-杭州站收藏星标.png`。

另修复地图定位偏移：收藏地点（星标）此前在高德地图上误用了 WGS-84 坐标（`mapLocation`，是给 Leaflet/OSM 备用地图用的），导致星标比实际位置偏移约几百米；现改为使用高德需要的 GCJ-02 坐标（`location`），星标与高德底图对齐。当天地点、路线折线和定位此前已用正确坐标，不受影响。验收脚本 `../验证工具/check-map-star-position.cjs`。

本轮把地点坐标字段重命名为带坐标系的名称，从命名上杜绝坐标系混用：`location` → `gcj02`（高德/腾讯坐标系）、`mapLocation` → `wgs84`（Leaflet/OSM 坐标系），`lng`/`lat` 保留为 WGS-84 数字。涉及 `providers.cjs`、`amap-map.js`、`map-interactions.js`、`live-data.js`、`entry-controls.js`。浏览器里已保存的旧数据会在加载时自动迁移（`location`→`gcj02`、`mapLocation`→`wgs84`），无需手动处理，验收脚本 `../验证工具/check-migrate-fields.cjs`。
